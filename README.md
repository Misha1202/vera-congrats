# Вера — анимированное поздравление 🌸

Красивая анимированная страница поздравления с днём рождения в японском стиле: падающие лепестки сакуры, луна, фейерверки и светящийся заголовок.

Открывается по адресу: **https://misha1202.github.io/vera-congrats/**

## Публикация

Страница публикуется автоматически через GitHub Pages — любой пуш в `main` обновляет сайт.
